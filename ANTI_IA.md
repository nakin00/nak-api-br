# Princípio do nak.api.br: NÃO PODE TER CARA DE IA

Esta é a regra mais importante do projeto. Vale pra layout, pra escrita, pra geração automática.

## Por quê?

A própria geração automatizada deste portal (drafter Gemini + gerador HTML) vai virar um case publicado aqui. Se o portal cheirar a IA, o case se autoinvalida.

## Checklist antes de publicar qualquer coisa

### Linguagem
- [ ] Nenhuma palavra da lista proibida: `revolucionário`, `disruptivo`, `transformador`, `potencialize`, `alavanque`, `estratégico`, `robusto` (solto), `escalável` (solto), `inovador`, `inteligente` (adjetivo vazio), `poderoso`, `completo`.
- [ ] Nenhuma frase fofa: "deixe sua marca", "transforme seu negócio", "imagine se", "você vai amar", "na era digital".
- [ ] Nenhuma abertura de redação de IA: "Em um cenário onde...", "Cada vez mais...", "Não é segredo que...".
- [ ] Nenhuma conclusão de IA: "Em suma", "Em resumo", "Vale ressaltar", "É importante destacar".
- [ ] Frases curtas. Sem subordinada-dentro-de-subordinada.
- [ ] Voz ativa. "Fiz", não "foi feito".
- [ ] Números reais quando existirem. Quando não, "alguns" / "vários" — nunca inventar.

### Layout
- [ ] Sem emoji decorativo (✨🚀🎉💡).
- [ ] Sem gradiente neon, cyberpunk, "AI-vibes".
- [ ] Sem ícones flutuantes coloridos genéricos.
- [ ] Paleta dark sóbria, tipografia técnica.
- [ ] Visuais (logs, snippets, dashboards, fluxogramas) sempre com dados REAIS da automação, não placeholders genéricos.

### Estrutura
- [ ] Cada case tem dor REAL com nome de coisa concreta.
- [ ] Insights são frases curtas, de quem viveu — não generalizações.
- [ ] Mostra também o que deu errado, não só o sucesso.

## Quando em dúvida

Lê em voz alta. Se soa como vendedor de curso, refaz. Se soa como você explicando pra uma colega num café, tá certo.
